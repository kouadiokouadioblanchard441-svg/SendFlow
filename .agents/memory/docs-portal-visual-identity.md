---
name: Documentation portal visual identity
description: User-required relationship between the API documentation portal and SendFlow legal-page visual style.
---

The documentation portal must use a pure white background, dark writing like the legal pages, saturated SendFlow violet accents, and clearly visible, sturdy card borders. Do not drift to a beige background or a blue primary theme.

**Why:** the user explicitly corrected repeated visual mismatches and asked for the documentation to match the legal-page colors and visual solidity.

**How to apply:** preserve white surfaces, dark text, strong violet accents, and solid card boundaries across desktop and mobile when changing the documentation portal.
